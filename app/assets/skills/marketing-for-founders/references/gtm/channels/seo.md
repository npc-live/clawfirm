# 📈 SEO

## When to use this channel

SEO is a **long-term bet** — typically takes 3–6 months before you see meaningful organic traffic. Don't focus on it in the first 30 days, but don't ignore it either. Start laying the foundation early.

**Best for:** Startups with a clear search demand (people actively Googling for the problem you solve).

**Not worth early effort for:** Products solving a problem people don't know they have yet.

## Keyword research

- [How to do keyword research for SEO and AEO](https://www.marketermilk.com/blog/how-to-do-keyword-research)

Keyword types to target:
1. **Problem keywords**: "how to [solve X]" — high intent, people aware of problem
2. **Solution keywords**: "[your category] software" — they know what they want
3. **Alternative keywords**: "[competitor] alternative" — steal competitor traffic
4. **Use case keywords**: "[your tool] for [specific use case]"

## Content strategy approaches

### Use-case-led SEO
Create pages for each specific use case your product solves. Works for SaaS with multiple verticals.
- [Use-case-led SEO: A strategy for sustainable organic growth](https://playbooks.hypergrowthpartners.com/p/use-case-led-seo-a-strategy-for-organic)

### Programmatic SEO
Generate hundreds/thousands of pages programmatically using templates + data. Works for marketplaces, directories, comparison tools.
- [The HyperGrowth Partners Guide to AI-powered Programmatic SEO](https://playbooks.hypergrowthpartners.com/p/ai-powered-programmatic-seo)
- [The Complete Guide to Programmatic SEO](https://www.withdaydream.com/access/pseo#chapter-one-the-rise-of-programmatic-seo)

### UGC SEO
User-generated content (reviews, profiles, forum posts) becomes SEO content at scale.
- [The Future of SEO is User-Generated Content](https://www.elenaverna.com/p/the-future-of-seo-is-user-generated)

## Early-stage SEO checklist (do these now, not later)

- [ ] Set up Google Search Console (free, shows what queries bring you traffic)
- [ ] Set up basic sitemap.xml
- [ ] Make sure each page has a unique `<title>` and meta description
- [ ] Create a `/blog` or `/resources` section (even if empty) so you can add content later
- [ ] Write 2–3 articles targeting your highest-value keywords
- [ ] Get listed on 10+ directories (backlinks matter) — see `launch-platforms.md`

**Don't:**
- Buy backlinks
- Write thin AI-generated content in bulk
- Chase high-competition keywords as a new site

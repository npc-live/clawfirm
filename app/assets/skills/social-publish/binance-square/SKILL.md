# 币安广场 (Binance Square) 内容创作

## 文案风格

### 核心调性：专业可信 + 数据驱动 + Web3 原生

- **专业**：有理有据，引用链上数据/技术指标/项目文档
- **观点鲜明**：做"分析师"不做"喊单"——分析 > 预测
- **Web3 原生**：熟悉行业术语，但不堆砌黑话
- **数据驱动**：用数据说话，图表 > 文字描述
- **中英双语**：根据目标受众选择，币安广场国际化程度高

### 语气参考

```
行情分析型: "BTC 突破 $XX,000。三个链上关键数据告诉你接下来走势..."
项目解读型: "{项目名} 主网上线 — 架构深度解析 + 对生态的影响"
教程科普型: "新手必看：如何安全存储你的加密资产（5步指南）"
观点型: "Unpopular take: {Web3 观点}. Here's why..."
事件速报型: "{事件} — 对市场意味着什么？三个维度解读"
数据型: "链上数据速递：{指标}创新高/低，这意味着..."
```

### 避免的写法

```
避免:
  - 喊单式: "冲！买！梭哈！"
  - 空洞鸡汤: "相信区块链的力量"
  - 标题党: "震惊！XX币要暴涨1000倍"
  - 堆砌术语: 无实质内容的专业名词堆叠
  - FOMO 诱导: "最后机会""再不买就晚了"

推荐:
  - 结构化分析（论点 → 数据 → 结论）
  - 客观中立（正反两面都提及）
  - 有信息增量（读完有收获）
```

## 标签策略

### 基本规则

- 每帖 3-5 个标签（过多不利于推荐）
- `$代币` 标记：自动关联币种页面（如 $BTC $ETH）
- `#话题` 标签：分类和发现（如 #DeFi #Write2Earn）
- 标签放在帖子末尾，不要插在正文中间

### 标签选择

```
必选（1个大类标签）:
  $BTC  $ETH  #DeFi  #NFT  #Web3  #Crypto

可选（1-2个活动标签）:
  #BinanceSquare  #Write2Earn  #CryptoAnalysis
  #MarketUpdate  #TradingView

可选（1-2个赛道标签）:
  #Layer2  #RWA  #AI  #GameFi  #Meme
  #Solana  #BNBChain  #Bitcoin  #Ethereum

避免:
  与内容无关的标签
  过度营销标签
  > 5 个标签
```

## 风控规则

详见 → `references/content-rules.md`

### 关键合规要点

| 风险行为 | 后果 |
|----------|------|
| 明确投资建议（"立刻买入"） | 内容删除 / 限流 |
| 承诺收益（"稳赚""保本"） | 内容删除 / 封号 |
| 发布合约地址 | 内容删除 / 封号 |
| 虚假盈利截图 | 内容删除 / 永久封禁 |
| 抄袭他人内容 | 内容删除 / 封号 |
| 短时间大量发帖 | Spam 标记 / 限流 |
| FOMO 诱导语言 | 降权 / 限流 |

### 合规文案必备

```
分析类帖子结尾必加:
  "以上仅为个人分析，不构成投资建议。NFA/DYOR"
  或 "This is not financial advice. DYOR."

数据类帖子标注来源:
  "数据来源：CoinGecko / Glassnode / Binance / DeFiLlama"

安全措辞替换:
  ❌ "立刻买入" → ✅ "值得关注"
  ❌ "稳赚不赔" → ✅ "风险收益比较优"
  ❌ "All in"   → ✅ "可考虑适度配置"
  ❌ "100x"     → ✅ "有较大上行空间"
  ❌ "最后机会" → ✅ "当前处于关键位置"
  ❌ "肯定涨"   → ✅ "从技术面看有X概率"
```

## 算法适配

详见 → `references/algorithm-guide.md`

### 推荐因子权重

```
权重排序:
  1. 评论/回复      — 最高权重（引发讨论 = 好内容）
  2. 分享/转发      — 高权重（用户愿意传播 = 有价值）
  3. 点赞           — 中等权重（基础互动信号）
  4. 收藏/书签      — 中等权重（长期价值信号）
  5. 阅读停留时间   — 中等权重（内容质量信号）
  6. 作者信誉分     — 加分项（Top Creator 加权）
```

### 算法友好策略

| 策略 | 说明 |
|------|------|
| 鼓励评论 | 末尾提问 / 争议观点 / "你怎么看？" |
| 内容深度 | 长文+数据 > 纯观点（增加停留时间） |
| 时效性 | 紧跟市场热点（BTC波动、政策、项目事件） |
| 视觉元素 | K线图/数据图表/信息图 增加互动 |
| 互动回馈 | 积极回复评论（偏好互动活跃的创作者） |
| 稳定频率 | 每日1-3条（优于一次性大量发帖） |
| $代币标记 | 使用 $BTC $ETH 等关联币种页面获取额外流量 |

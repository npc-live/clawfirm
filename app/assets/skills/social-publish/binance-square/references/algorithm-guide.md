# 币安广场推荐算法

## Feed 推荐机制

### 推荐来源

```
币安广场 Feed 组成:
  - 关注的创作者内容
  - 算法推荐的热门/相关内容
  - 官方活动/精选内容（置顶/推荐位）
  - 与用户持仓相关的代币资讯
  - Trending（热门话题）内容

内容分发路径:
  发布 → 粉丝 Feed → 算法评估 → 扩大分发（或不扩大）
```

### 推荐因子权重

```
正面因子（按权重排序）:
  1. 评论/回复         ★★★★★  (最高权重 — 引发讨论=好内容)
  2. 分享/转发          ★★★★   (用户愿意传播=有价值)
  3. 点赞               ★★★    (基础互动信号)
  4. 收藏/书签          ★★★    (长期价值信号)
  5. 阅读停留时间       ★★★    (内容质量信号)
  6. 作者信誉分         ★★     (Top Creator 加权)
  7. 内容时效性         ★★     (新鲜内容优先)
  8. 代币相关性         ★      (与用户持仓/关注匹配)

负面因子:
  - 被举报              (极大负面 — 可能直接降权或删除)
  - 被隐藏/不感兴趣    (负面 — 影响后续推荐)
  - 低互动率            (相对负面 — 曝光后无人互动)
  - 高跳出率            (负面 — 用户看了标题就走)
```

### 关键洞察

```
1. 评论 >> 一切
   引导用户评论比引导点赞更有价值
   技巧: 末尾提问 / 争议观点 / 数据征集

2. 分享 > 点赞
   用户分享到社交媒体是强正面信号
   技巧: 提供可引用的金句/数据

3. 停留时间很重要
   长文/数据图表/视频 → 增加停留时间
   纯文字短帖停留时间短，权重相对低

4. 代币标记 $BTC 有额外曝光
   使用 $ 标记会出现在对应币种的 Feed 中
   = 额外流量入口
```

## 流量池机制

### 三级分发模型

```
阶段1: 初始池（发布后 0-30 分钟）
  - 推送给: 粉丝 + 少量算法推荐用户
  - 评估指标: 互动率（评论/点赞/停留时间）
  - 样本量: 约 100-500 次曝光（取决于粉丝数）

阶段2: 扩大池（30分钟-6小时）
  - 条件: 阶段1互动率达标
  - 推送给: 更大范围的兴趣匹配用户
  - 可能进入: "推荐"/"发现"/"相关话题" Feed
  - 样本量: 约 1,000-10,000 次曝光

阶段3: 热门池（6-48小时）
  - 条件: 持续高互动率
  - 推送给: 全站推荐 / Trending
  - 可能被: 精选/官方推荐
  - 效果: 数万-数十万曝光

衰减: 48小时后权重明显下降，除非持续获得新互动
```

### 黄金窗口期

```
关键: 发布后 30-60 分钟决定内容命运

优化策略:
  1. 在粉丝最活跃时段发布
  2. 发布后立即在评论区补充关键信息（自评论）
  3. 主动回复前几条评论（制造互动氛围）
  4. 分享到其他社交媒体引流（Twitter/Telegram）
  5. 不要在同一小时内发多条帖子（互相抢流量）
```

## 创作者等级系统

### 等级与权重

```
普通用户:
  - 基础推荐权重
  - 内容需通过审核
  - 无特殊展示位

认证创作者（Verified Creator）:
  - 较高推荐权重
  - 内容优先审核
  - 创作者标签展示
  - 可参与 Write2Earn

Top Creator:
  - 最高推荐权重
  - 曝光加成（更大的初始分发池）
  - 可能获得首页推荐位
  - 官方活动优先邀请

KOL/官方合作:
  - 特殊推荐位
  - 官方认证标签
  - 独占活动/AMA 机会
```

### 升级路径

```
提升创作者等级:
  1. 持续输出高质量内容（每周≥3篇）
  2. 保持高互动率（评论/点赞/分享）
  3. 粉丝增长稳定（非买粉）
  4. 内容零违规
  5. 参与官方活动（Write2Earn 等）
  6. 内容准确度高（尤其是分析/预测类）
```

## Write2Earn 机制

### 概述

```
Write2Earn 是币安广场的创作者激励计划:
  - 持续输出高质量内容可获得代币奖励（通常为 FDUSD 或特定活动代币）
  - 奖励基于: 内容质量 × 互动量 × 创作者等级
  - 定期有专题活动，参与特定话题可获得额外奖励

参与条件:
  - 认证创作者身份
  - 内容符合社区准则
  - 使用官方指定标签（如 #Write2Earn）
```

### 最大化 Write2Earn 收益

```
策略:
  1. 关注官方活动公告（新活动 = 新奖励池）
  2. 使用活动指定标签
  3. 内容聚焦活动主题
  4. 保持高互动率（直接影响奖励金额）
  5. 长文 > 短帖（深度内容奖励系数更高）
  6. 原创 > 转述（原创内容优先获得奖励）
```

## 内容类型偏好

### 算法偏好的内容

```
高推荐概率:
  + 有数据/图表的分析帖（增加停留时间 + 可信度）
  + 长文章（深度内容，高停留时间）
  + 视频内容（高互动率）
  + 热点事件速报（时效性加分）
  + 引发大量评论的帖子
  + 使用 $代币 标记的帖子（进入币种 Feed）
  + 原创内容（非转载/搬运）

低推荐概率:
  - 纯文字无图短帖（低停留时间）
  - 重复/模板化内容（Spam 嫌疑）
  - 纯外部链接（无自有内容）
  - 与加密无关的内容
  - 低互动的帖子（初始池淘汰）
```

### 各类型内容策略

```
短帖策略:
  - 配图/图表（+50% 互动）
  - 末尾提问引导评论
  - 使用 $代币 标记
  - 紧跟热点时效

长文策略:
  - 结构清晰（标题/小节/结论）
  - 数据表格 + 图表
  - 原创深度分析
  - 封面图有吸引力

视频策略:
  - 前3秒抓注意力
  - 5-10分钟最佳长度
  - 配合文字描述和标签
  - 首帧设计为"封面"
```

## 互动优化策略

### 引导评论（最高权重）

```
技巧:
  - 末尾提问: "你怎么看？评论区聊聊"
  - 争议观点: 引发正反方讨论
  - 投票: 使用投票功能增加参与度
  - 数据征集: "你的持仓成本是多少？"
  - 预测: "BTC本周会到多少？评论区说出你的预测"
  - 经验分享: "你在XX赛道的最大收获是？"
```

### 增加停留时间

```
技巧:
  - 使用长文（逐段阅读）
  - 附带数据图表/K线分析图
  - 视频内容（自然增加停留）
  - 信息密集内容（需要时间消化）
  - 列表/步骤型内容（逐条阅读）
```

### 互动回馈

```
技巧:
  - 发布后30分钟内回复前5条评论
  - 评论区补充关键数据/信息
  - 对有深度的评论给予详细回复
  - 不要只回"谢谢"，提供有价值的互动
  - 定期回复粉丝提问（建立社区感）
```

## 时间衰减

```
内容时效性:
  - 黄金期: 发布后 30-60 分钟（决定是否进入扩大池）
  - 活跃期: 发布后 1-6 小时（持续获得推荐）
  - 长尾期: 6-48 小时（被分享/评论可延长）
  - 过期: >48小时（除非持续获得互动或被精选）

策略:
  - 在目标受众最活跃时段发布
  - 发布后30分钟内积极互动
  - 自评论补充信息（保持活跃度）
  - 重大行情波动时及时发布速评
```

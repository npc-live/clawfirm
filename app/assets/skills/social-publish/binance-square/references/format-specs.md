# 币安广场格式规范

## 帖子类型

### 1. 短帖（Quick Post / Short Post）

| 项目 | 规范 |
|------|------|
| 字符限制 | ≤1,000 字符 |
| 中文计算 | 1 中文字 ≈ 3 字节，约 330 个中文字 |
| 换行 | 支持，用于格式化 |
| 媒体 | 图片(最多9张) / 视频(1个) / 投票 |
| 链接 | 支持，可嵌入外部链接 |
| 标签 | #话题 和 $代币 标记，建议 3-5 个 |
| 适用场景 | 快速观点、行情速评、每日简报、事件速报 |

---

### 2. 长文章（Long-form Article）

| 项目 | 规范 |
|------|------|
| 标题 | ≤100 字符 |
| 正文 | ≤20,000 字符 |
| 富文本 | 支持标题(H1-H3)、加粗、斜体、列表、代码块、引用、链接 |
| 封面图 | 推荐 1200×675（16:9 比例） |
| 内嵌图片 | 支持在正文中插入图片 |
| 适用场景 | 深度分析、项目研报、教程指南、周报月报 |

#### 长文结构建议

```
推荐结构:
  标题: 简洁有力，含关键词和代币标记（$BTC）
  封面图: 数据图表/K线/项目Logo（高辨识度）
  
  ## 引言
  - 1-2段，说明分析背景和目的
  
  ## 正文（2-4个小节）
  - 每节一个核心论点
  - 配合数据/图表/案例
  - 引用标注来源
  
  ## 结论
  - 简洁总结
  - 展望/预判（标注NFA）
  
  ## 免责声明
  - 标准 NFA/DYOR 声明
  
  标签: 3-5 个
```

---

### 3. 视频帖

| 项目 | 规范 |
|------|------|
| 时长 | ≤60 分钟（推荐 1-10 分钟） |
| 格式 | MP4（H264 视频编码 + AAC 音频编码） |
| 分辨率 | 推荐 1080p（1920×1080），支持 720p-4K |
| 大小 | ≤1GB |
| 帧率 | 24-60fps |
| 码率 | 推荐 ≤15Mbps |
| 比例 | 16:9（横屏）/ 9:16（竖屏）/ 1:1（方形） |
| 封面 | 自动截取首帧，不支持自定义 |
| 描述 | ≤1,000 字符 |

#### 视频技巧

```
封面优化:
  - 视频首帧即"封面"，确保有吸引力
  - 可在视频开头插入"标题帧"（含文字+数据）
  - 高对比度、大字体（手机端清晰）

推荐时长:
  行情速评: 1-3 分钟
  项目分析: 5-10 分钟
  教程指南: 5-15 分钟
  深度研报: 10-30 分钟

音频:
  - 清晰无杂音
  - 推荐使用外接麦克风
  - 背景音乐音量不超过语音的 20%
```

## 图片规范

### 基本参数

| 项目 | 规范 |
|------|------|
| 格式 | JPG, PNG, GIF, WEBP |
| 大小 | ≤5MB/张 |
| 数量 | 最多 9 张/帖 |
| GIF | 支持，≤10MB |

### 图片尺寸推荐

| 场景 | 比例 | 尺寸 |
|------|------|------|
| 单图(横) | 16:9 | 1200×675 |
| 单图(方) | 1:1 | 1080×1080 |
| 封面图 | 16:9 | 1200×675 |
| 信息图 | 不限 | 宽 ≥800px |
| K线截图 | 16:9 | 1920×1080 |
| 数据图表 | 16:9 或 4:3 | 1200×675 或 1200×900 |

### 图片最佳实践

```
推荐:
  - 高对比度（手机端清晰可辨）
  - 文字大号清晰（可在 feed 中直接阅读）
  - 数据图表标注清晰（坐标轴、图例、数据标签）
  - K线图标注关键位置（支撑/阻力/趋势线）
  - 品牌/水印统一（建立个人品牌辨识度）

避免:
  - 低分辨率/模糊的截图
  - 文字过小无法在手机上阅读
  - 大面积纯色无信息量
  - 未标注来源的数据图表
  - 带有其他平台水印的图片
```

## 标签规范

### 标签类型

| 类型 | 前缀 | 示例 | 说明 |
|------|------|------|------|
| 代币标记 | $ | $BTC $ETH $SOL | 自动关联币种行情页面 |
| 话题标签 | # | #DeFi #Write2Earn | 分类和话题发现 |

### 标签使用规则

```
数量: 3-5 个（过少不利于发现，过多降权）

放置位置: 
  - 帖子末尾（推荐）
  - 不要在正文中间插入标签（影响阅读体验）

组合建议:
  1个代币标记（$BTC）+ 1-2个大类标签（#Crypto）+ 1-2个赛道标签（#Layer2）

热门标签（持续有效）:
  $BTC  $ETH  $BNB  $SOL
  #Bitcoin  #Ethereum  #Crypto  #Web3  #DeFi
  #BinanceSquare  #Write2Earn  #CryptoAnalysis
  #MarketUpdate  #TradingView  #TechnicalAnalysis

赛道标签:
  #Layer2  #RWA  #AI  #GameFi  #Meme  #NFT
  #Staking  #Airdrop  #DePIN  #ZK

避免的标签:
  - 与内容无关的热门标签（降权）
  - 过于细分无人搜索的标签
  - 营销性质过强的标签
```

## 投票功能

| 项目 | 规范 |
|------|------|
| 选项数 | 2-4 个 |
| 选项长度 | 简短清晰 |
| 时长 | 1-7 天 |
| 组合 | 与短帖文字组合使用 |
| 适用 | 市场情绪调查、社区观点收集 |

```
投票示例:
  "你认为 BTC 年底会到多少？"
  □ > $100K
  □ $80K-100K
  □ $60K-80K
  □ < $60K

  "下一个爆发的赛道是？"
  □ AI + Crypto
  □ RWA
  □ DePIN
  □ GameFi
```

## 排版建议

### 短帖排版

```
好的排版:
  [Hook一句话 — 数据/事件/观点]

  [要点1 — 数据支撑]
  [要点2 — 分析论证]
  [要点3 — 结论展望]

  你怎么看？评论区聊聊 👇

  #Tag1 #Tag2 $BTC
  NFA/DYOR

避免:
  一大段不分段的文字
  只有标签没有内容
  纯表情/符号
  复制粘贴的模板化内容
```

### 使用换行增加可读性

```
技巧:
  - 用空行分隔不同论点
  - 用数字/emoji作为列表标记
  - 短句 > 长句
  - 数据单独成行（突出重点）
  - 关键结论加粗或用引号标注
```

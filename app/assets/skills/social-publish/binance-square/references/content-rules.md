# 币安广场平台规则

## 社区准则核心政策

### 禁止内容类别

#### 1. 虚假与误导性信息

```
严格禁止:
  - 虚假新闻、伪造截图、虚假项目信息
  - 虚假盈利/交易记录截图
  - 未经核实的"内幕消息"
  - 故意操纵市场情绪的内容
  - AI 生成的虚假市场数据
  - 伪装成官方公告的第三方信息

后果: 内容删除 + 警告，严重者永久封禁
```

#### 2. 金融诈骗与非法活动

```
严格禁止:
  - 庞氏骗局 / 传销推广
  - 钓鱼链接 / 恶意合约地址
  - 代投、代挂、保本保息承诺
  - 场外 OTC 洗钱交易
  - 非法赌博平台推广
  - 假冒项目方募资
  - 代币预售诈骗

后果: 内容删除 + 永久封禁 + 可能上报执法机构
```

#### 3. 投资建议合规（核心要点）

```
禁止:
  - 明确的买入/卖出指令
    ❌ "All in XXX"  "立刻买入"  "100x确定"  "马上抄底"
  - 承诺收益
    ❌ "稳赚"  "保本"  "月化20%"  "包赚"  "零风险"
  - FOMO 情绪诱导
    ❌ "最后机会"  "明天就暴涨"  "再不买就晚了"  "错过就没了"
  - 喊单行为
    ❌ "今晚挂多单"  "这个位置做空"  "止损设在XXX"

要求:
  - 分析性内容必须标注 "NFA"（Not Financial Advice）或 "DYOR"
  - 数据分析标明信息来源和数据出处
  - 区分"个人观点"和"客观事实"
  - 提及风险因素，不能只说利好

允许:
  - 基于链上数据/技术指标的客观分析（标注NFA）
  - 项目技术/生态/团队的客观研究报告
  - 宏观经济分析对加密市场的影响分析
  - 教育科普类内容（钱包使用、DeFi原理等）
```

#### 4. 项目推广规则

```
禁止:
  - 未经币安认证的项目代币硬广
  - 发送合约地址让用户购买
  - Pump & Dump 行为（先拉盘后砸盘）
  - 以"研究"为名的软广（收费推广不披露）
  - 虚假空投信息诱导操作
  - 推广未经审计的 DeFi 协议

允许:
  - 对已上线币安的项目进行客观分析
  - 参与 #Write2Earn 等官方活动的内容创作
  - 开源项目/协议的技术分析
  - 标明"付费推广"的合作内容（需遵守披露规则）
```

#### 5. 侵权与不当内容

```
禁止:
  - 抄袭他人内容（严格查重，被发现可封号）
  - 仇恨言论、人身攻击
  - 色情/暴力/血腥内容
  - 骚扰其他用户
  - 非 Web3 相关的商业广告
  - 政治敏感内容
  - 地域/种族歧视
```

## Spam 防控机制

### 触发 Spam 标记

```
触发条件:
  - 短时间内大量重复帖子（≥5条/小时内容相似）
  - 复制粘贴相同内容到多个帖子
  - 每条帖子都带外部链接
  - 批量评论相同内容（"nice" "good" "+1"）
  - 自动化发帖行为特征（固定间隔、机械式）
  - 大量使用无关标签蹭流量
  - 频繁在他人帖子下发广告评论
```

### 安全做法

```
安全阈值:
  - 每日发帖 ≤10 条
  - 每条帖子内容独特（相似度 <60%）
  - 外部链接帖 < 30% 的总发帖量
  - 评论有实质内容（≥20字符）
  - 发帖间隔自然随机（≥10分钟）
  - 标签数量 3-5 个/帖

推荐:
  - 混合发帖类型（短帖 + 长文 + 互动）
  - 真实互动（回复评论、参与讨论）
  - 内容有信息增量
```

## 内容降权因素

### 确认降权

```
明确降权:
  - 被多人举报的内容
  - 包含钓鱼链接/恶意地址
  - 纯广告无价值内容
  - 重复内容（与自己或他人重复）
  - 违反社区准则被标记的内容
```

### 可能降权

```
可能降权:
  - 过多外部链接（非 Binance 域名）
  - 标题党（clickbait）— 标题与内容不符
  - 只发帖不互动（低回复率）
  - 与加密无关的内容（off-topic）
  - 纯图片无文字说明
  - 机械式转发他人内容
```

### 降权处理建议

```
如果怀疑被降权:
  1. 检查近期内容是否触发规则
  2. 减少发帖频率，提高内容质量
  3. 增加真实互动（回复评论、参与讨论）
  4. 避免外部链接，改用截图
  5. 确保每篇内容有独特价值
```

## 账号信用体系

### 正面信号

```
提升账号权重:
  + 持续输出高质量分析（每周≥3篇有深度内容）
  + 获得大量互动（点赞/评论/分享）
  + 获得 "Top Creator" / "认证创作者" 标签
  + 参与官方活动（Write2Earn）
  + 内容准确率高（预测/分析准确度）
  + 账号活跃时间长
  + 粉丝增长稳定自然
```

### 负面信号

```
降低账号权重:
  - 被多次举报
  - 内容违规被删除（累计≥3次严重违规可封号）
  - 发布虚假信息
  - Spam 行为
  - 大量粉丝为机器人/僵尸号
  - 频繁删帖（试图规避审核）
  
永久封禁风险:
  - 多次严重违规
  - 金融诈骗行为
  - 恶意操纵市场
  - 大规模 Spam 攻击
```

## 合规文案写作规范

### 必须加的免责声明

```
分析类:
  "以上仅为个人分析，不构成投资建议。NFA/DYOR"
  "This is not financial advice. Always DYOR."

数据类:
  "数据来源：[CoinGecko/Glassnode/Binance/DeFiLlama]，仅供参考"
  "Data sourced from [X]. Verify independently."

预测类:
  "以上为个人观点，市场有风险，投资需谨慎"
  "Past performance does not guarantee future results."

教程类:
  "以上操作涉及加密资产，请确保理解相关风险"
```

### 安全措辞替换表

```
投资建议替换:
  ❌ "立刻买入"   → ✅ "值得关注"
  ❌ "稳赚不赔"   → ✅ "风险收益比较优"
  ❌ "All in"     → ✅ "可考虑适度配置"
  ❌ "100x"       → ✅ "有较大上行空间"
  ❌ "最后机会"   → ✅ "当前处于关键位置"
  ❌ "肯定涨/跌"  → ✅ "从技术面看有X概率"
  ❌ "内幕消息"   → ✅ "链上数据显示"
  ❌ "抄底"       → ✅ "逐步建仓"
  ❌ "梭哈"       → ✅ "增加仓位"
  ❌ "跑路"       → ✅ "项目方疑似停止运营"
  ❌ "割韭菜"     → ✅ "零售投资者损失较大"

情绪替换:
  ❌ "暴涨"       → ✅ "大幅上涨"
  ❌ "崩盘"       → ✅ "出现较大跌幅"
  ❌ "归零"       → ✅ "价格大幅缩水"
  ❌ "财富密码"   → ✅ "潜力项目分析"
```

### 发帖前检查清单

```
发布前自检:
  □ 不含明确投资建议措辞
  □ 分析类内容已标注 NFA/DYOR
  □ 数据已标明来源
  □ 不含未经验证的合约地址
  □ 不含钓鱼链接
  □ 内容原创（非复制粘贴）
  □ 标签数量 3-5 个
  □ 没有承诺收益的表述
  □ 提及了风险因素
  □ 语气客观中立
```

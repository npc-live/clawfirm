# 抖音内容创作

## 文案风格

### 核心调性：口语化、信息密度高、节奏快

- **口语化**：像跟朋友说话，不要播音腔
- **前 3 秒定生死**：开场必须有强 Hook
- **信息密度**：每秒都要有信息量，不能"注水"
- **节奏感**：用语速变化、停顿、重音控制节奏
- **悬念感**：每个段落结尾留悬念，防止划走

### 口播模板

```
Hook（0-3s）:
  "[痛点/成果/反常识] + 今天就教你[解决方案]"

正文（3s-50s）:
  "第一步..., 第二步..., 第三步..."
  或 "首先..., 但关键是..., 最重要的是..."

CTA（最后5s）:
  "关注我，下期教你[下期预告]"
  "觉得有用就点赞收藏，分享给需要的朋友"
```

### 文案节奏技巧

```
短句: 用3-5字短句增加节奏感
  "注意。这很重要。记住了。"

反转: 先说常识，再推翻
  "你以为...？其实不是。真相是..."

数字具象化: 用具体数字代替模糊描述
  "3个月" > "一段时间"
  "涨了2万粉" > "涨了很多粉"

重复强调: 关键信息重复2-3次
  "完播率，完播率，还是完播率"
```

## 格式规范

### 视频规格

| 项目 | 规范 |
|------|------|
| 比例 | 竖屏 9:16（1080×1920） |
| 格式 | MP4 / MOV |
| 大小 | ≤4GB |
| 帧率 | 30fps / 60fps |
| 编码 | H.264 推荐 |

### 时长分级

| 时长 | 适用场景 | 难度 |
|------|----------|------|
| ≤15s | 热梗、快节奏、种草 | ★ |
| 15-60s | 教程、口播、故事 | ★★ |
| 1-3min | 深度教程、剧情、vlog | ★★★ |
| 3-10min | 专题、评测、长故事 | ★★★★ |

### 封面规范

```
尺寸: 1080×1440（3:4）或 1080×1920（9:16）
要素:
  - 大字标题（≤8字）
  - 高对比度
  - 人物出镜（有人脸封面点击率+30%）
  - 关键数字突出显示

避免:
  - 纯黑/纯白背景
  - 文字太小
  - 信息过载
```

### 字幕规范

```
位置: 画面下方 1/3
字体: 黑体/加粗，白色+黑色描边
字号: ≥24pt（确保手机端清晰）
样式: 关键词用不同颜色高亮
时间: 与口播严格同步
```

### 视频看点/时间戳（Video Chapters）

抖音创作者服务平台支持为视频添加"看点"（章节时间戳），用户可在进度条上看到章节标记并点击跳转。

#### 平台规则

```
入口: 抖音创作者平台发布页 → "添加看点"按钮
格式: MM:SS 章节标题（分钟和秒均补零，如 00:00、01:30、12:45）
填写方式: 通过发布页 UI 逐条添加（非写在描述文案中）

硬性要求:
  - 视频时长 ≥ 1 分钟才可添加看点
  - 至少 3 个节点，否则不生效
  - 必须从 00:00 开始（第一个时间戳）
  - 每个章节间隔 ≥ 10 秒
  - 每个章节标题 ≤ 16 字（中文）
  - 时间戳必须按升序排列
  - 最后一个时间戳不能超过视频总时长
  - 最多 10 个看点节点
```

#### 数量建议

| 视频时长 | 建议章节数 | 说明 |
|----------|-----------|------|
| 1-3 分钟 | 3-5 个 | 短视频精简导航 |
| 3-5 分钟 | 4-6 个 | 每分钟约 1-2 个节点 |
| 5-10 分钟 | 5-8 个 | 中长视频标准密度 |
| 10+ 分钟 | 8-10 个 | 长视频上限 10 个 |

#### 时间戳撰写规范

```
格式示例:
  00:00 开场
  00:45 为什么你需要这个
  02:10 第一步：环境搭建
  04:30 实操演示
  07:00 效果展示与对比
  09:15 常见问题解答
  10:40 总结

标题写作原则:
  - 简短有力，一看就知道这段讲什么
  - 包含核心关键词（利于搜索推荐和分发）
  - 前 3-5 个字要有信息量（移动端显示截断）
  - 适当加悬念词（"揭秘""对比""翻车""实测"）
  - 用动词开头更有行动感（"搭建""配置""对比""拆解"）
  - 不用 emoji（UI 编辑器不支持/可能异常显示）
  - 不用标点符号结尾
```

#### 与完播率的关系

```
看点对完播率的影响:
  - 用户通过看点跳转到感兴趣的章节，减少中途划走
  - 进度条上的可视标记给用户"结构感"，降低长视频的阅读焦虑
  - 高质量看点标题本身是"钩子"，吸引用户继续看下一章节

优化策略:
  - 第 2-3 个看点标题放最吸引人的内容（用户最常跳转的位置）
  - 最后一个看点用总结/彩蛋/结论类标题（引导看完）
  - 看点间距不要太均匀——在核心内容段密集一些，过渡段稀疏
```

#### 从字幕提取看点的策略

```
输入: SRT 字幕文件 + 视频时长
步骤:
  1. 通读字幕内容，标记话题转折点
  2. 提取转折点对应的时间戳（取该段开始时间，精确到秒）
  3. 为每个节点撰写 ≤16字 概括标题
  4. 合并过于密集的节点（间距 < 30秒 考虑合并到前一节点）
  5. 确保总数 ≤ 10 个，超出时优先保留信息量最大的节点
  6. 第一个必须是 00:00，最后一个时间不超过视频总时长

质量检查:
  - 标题前5个字是否有信息量？（移动端截断测试）
  - 是否包含该领域用户可能搜索的词？
  - 看点标题连起来读，是否构成完整的内容摘要？
  - 间距是否合理？（避免前密后疏或前疏后密）
```

#### 合规注意事项

```
禁止:
  - 看点标题含违禁词（收益承诺、绝对化用语、医疗断言）
  - 用看点标题做引流（"加微信""私我"）
  - 虚假标记（时间戳与实际内容不对应）
  - 用看点标题蹭热点但内容无关（标题党行为）

注意:
  - 看点添加后可修改但不建议频繁改动（频繁编辑触发重审）
  - 优质看点有助于进入"视频看点"推荐频道获取额外流量
  - 抖音搜索可索引看点标题关键词
```

## 标题规则

### 视频标题（描述区）

| 规范 | 说明 |
|------|------|
| 字数 | 20-55 字（太短搜索权重低，太长显示不全） |

| 格式 | #话题 + 正文描述 |

### 标题公式

```

#话题标签 + 反差悬念
  "#副业赚钱 他辞职做抖音，第一个月收入让所有人沉默了"
```

## 审核规避

详见 → `references/content-rules.md`

### 双重审核机制

```
第一轮: 机器审核（发布后即时）
  - AI 识别画面内容
  - 语音转文字后审核
  - 标题/描述关键词审核
  - 音乐版权审核

第二轮: 人工审核（流量触发）
  - 进入更大流量池时触发
  - 更细致的内容判断
  - 可能推翻机审结果
```

### 高危内容

| 类别 | 风险 | 处理 |
|------|------|------|
| 医疗建议 | 极高 | 必须标注"非专业建议" |
| 收益承诺 | 极高 | 禁用"月入XX""保证赚钱" |
| 版权音乐 | 高 | 使用抖音商用音乐库 |
| 竞品提及 | 中 | 避免直接 @竞品或说竞品名 |
| 站外引流 | 高 | 不能出现微信号/二维码 |
| 未成年人 | 极高 | 涉及未成年人内容需格外谨慎 |

### 限流触发条件

```
确认限流:
  - 视频发布后 2 小时播放量 < 100
  - 连续多条视频播放异常低

可能原因:
  - 含违禁词/敏感词
  - 搬运/重复发布
  - 账号权重被降（历史违规）
  - 内容质量太低（完播率极低）
  - 硬广/过度营销

恢复方法:
  - 删除违规视频
  - 暂停发布 3-7 天
  - 发布高质量原创内容
  - 参与官方活动
```

## 算法适配

详见 → `references/algorithm-guide.md`

### 核心指标权重

```
权重排序:
  1. 完播率    — 王者指标（前3秒+整体节奏）
  2. 互动率    — 点赞+评论+转发+收藏
  3. 转发率    — 高权重互动
  4. 评论率    — 高权重互动
  5. 关注转化率 — 从内容到关注的转化
  6. 点赞率    — 基础互动
```

### 五级流量池

```
第1级: 300-500 播放（初始推荐）
  目标: 完播率 > 30%，互动率 > 3%
  ↓ 达标升级
第2级: 3000-5000 播放
  目标: 完播率 > 25%，互动率 > 5%
  ↓ 达标升级
第3级: 1万-5万 播放
  目标: 数据持续优异
  ↓ 达标升级
第4级: 10万-50万 播放
  ↓ 达标升级
第5级: 100万+ 播放（热门）
```

### 完播率优化策略

| 位置 | 策略 |
|------|------|
| 0-3s | 强 Hook（痛点/成果/反常识），留住观众 |
| 3-10s | 承诺价值（"看完你就知道..."），建立期待 |
| 中段 | 信息密度高+节奏变化，防止走神 |
| 结尾前 | 投放悬念/彩蛋预告，鼓励看完 |
| 最后 | CTA + 引导完播（"最后一步最重要"） |

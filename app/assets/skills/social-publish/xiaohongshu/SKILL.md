# 小红书内容创作

## 文案风格

### 核心调性：姐妹种草、真诚分享

- **口语化**：像和闺蜜聊天，不要书面语
- **emoji 友好**：每 2-3 句用 emoji 分隔，但不堆砌
- **分享感**：用"我""亲测""真的推荐"等第一人称
- **种草感**：具体感受 > 抽象描述（"涂上嘴巴嘟嘟的" > "效果很好"）
- **真实感**：适当暴露小缺点，增加可信度

### 语气词库

```
常用: 真的绝了 / 姐妹们 / 救命 / 谁懂 / 绝绝子 / yyds / 宝子们
赞叹: 也太好了吧 / 爱了爱了 / 直接封神 / 这也太绝了
推荐: 闭眼入 / 人手一个 / 不允许还有人不知道 / 必须安利
转折: 但是！/ 划重点 / 注意⚠️ / 避雷！
```

### 文案结构模板

```
【标题】emoji + 关键词 + 数字/利益点
【正文】
  第1段: Hook（痛点/成果/反常识）
  第2段: 核心内容（列点/步骤/对比）
  第3段: 个人体验/使用感受
  第4段: CTA（收藏 > 关注 > 评论）
【标签】2核心 + 3长尾 + 1热门
```

## 格式规范

### 图文笔记（主力形式）

| 项目 | 规范 |
|------|------|
| 图片数量 | 6-9 张最佳（≥3 张，≤18 张） |
| 图片尺寸 | 3:4（1080×1440）推荐，1:1 也可 |
| 封面图 | 第一张即封面，决定点击率 |
| 文字字数 | 500-700 字最佳（≥300 字获得搜索权重） |
| 图片格式 | JPG/PNG，≤20MB/张 |

### 封面设计要点

```
必须元素:
  - 大字标题（≤10 字）
  - 高对比度（深色文字 + 浅色背景 或反之）
  - 关键信息可视化（数字、对比图、清单预览）

避免:
  - 纯文字无图（点击率低）
  - 文字过小（手机端看不清）
  - 信息过载（一张图一个核心信息）
```

### 视频笔记

| 项目 | 规范 |
|------|------|
| 比例 | 竖屏 9:16（1080×1920）推荐 |
| 时长 | 1-3 分钟最佳 |
| 格式 | MP4, ≤5GB |
| 字幕 | 必须有字幕，平台自动识别 + 手动校正 |
| 封面 | 可自定义，建议和图文封面同样设计 |

### 视频时间线/章节（Video Chapters）

小红书视频笔记支持在描述文案中嵌入时间线，平台会自动识别为可点击的进度条章节标记。

#### 平台规则

```
格式: M:SS 章节标题（注意：分钟部分不补零，使用 0:00 而非 00:00）
位置: 写在笔记描述正文中（非 UI 编辑器独立填写）
识别: 平台自动解析描述中的时间戳格式，渲染为视频进度条上的可点击章节

硬性要求:
  - 至少 3 个时间节点，否则不触发章节识别
  - 必须从 0:00 开始（第一个时间戳）
  - 每个章节间隔 ≥ 10 秒
  - 章节标题 ≤ 15 字（中文），简洁概括该段内容
  - 时间戳必须与视频实际进度对应（误差 ≤ 3 秒）
  - 时间戳按升序排列，不可乱序
```

#### 数量建议

| 视频时长 | 建议章节数 | 说明 |
|----------|-----------|------|
| 1-3 分钟 | 3-5 个 | 短视频保持精简 |
| 3-10 分钟 | 5-8 个 | 中视频标准密度 |
| 10-30 分钟 | 8-12 个 | 长视频每 2-3 分钟一个节点 |
| 30+ 分钟 | 10-15 个 | 超长视频不宜超过 15 个 |

#### 时间线撰写规范

```
格式示例:
  0:00 开场介绍
  0:44 核心理念
  3:08 技术方案解析
  11:00 实战演示
  15:30 效果对比
  20:00 运营策略
  23:00 数据复盘
  28:00 未来规划
  33:30 Q&A 答疑
  38:00 结束

标题写作原则:
  - 用动词或名词短语，不用完整句子
  - 包含该段核心关键词（利于搜索推荐）
  - 避免"第一部分""Part 1"等无信息量标题
  - 适当加入利益点/悬念（"3步搞定""揭秘""对比"）
  - 不使用 emoji（时间线中 emoji 可能干扰解析）
```

#### 在描述中的放置位置

```
推荐结构:
  [正文第1段: Hook / 核心价值]
  [正文第2段: 要点列表 / 内容概述]
  
  ⏱️ 视频时间线：
  0:00 开场介绍
  0:44 核心理念
  ...
  
  [CTA: 收藏/关注引导]
  [标签: #话题1 #话题2 ...]

注意:
  - 时间线放在正文之后、标签之前
  - 可用 "⏱️ 视频时间线：" 或 "📍 章节导航：" 作为引导语
  - 引导语本身不影响时间戳识别
  - 确保时间戳行独立成行，前面不加其他文字
```

#### 从字幕提取章节的策略

```
输入: SRT 字幕文件 + 视频时长
步骤:
  1. 通读字幕，识别话题转折点（语义变化、新问题引入、演示切换）
  2. 提取转折点对应的时间戳（取该段开始时间）
  3. 为每个时间点撰写 ≤15字 的概括性标题
  4. 合并过于密集的节点（间隔 < 30秒 的考虑合并）
  5. 确保第一个是 0:00，最后一个不超过视频时长

质量检查:
  - 章节标题是否一看就知道该段讲什么？
  - 是否包含用户可能搜索的关键词？
  - 间距是否均匀合理？
  - 总数量是否在推荐范围内？
```

#### 合规注意事项

```
禁止:
  - 时间戳对应到广告/引流内容（平台会识别为营销行为）
  - 章节标题含绝对化用语（"最强""唯一""100%"）
  - 虚假时间戳（与实际视频内容不对应）

建议:
  - 时间线准确有助于提升完播率和用户体验分
  - 高质量章节可增加搜索曝光（章节标题被索引）
  - 用户可通过章节直接跳转，降低跳出率
```

## 标题规则

### 基本规范

- 字数：≤20 字（含 emoji）
- 关键词前置（搜索权重集中在前 10 字）
- 至少包含 1 个数字
- 至少包含 1 个 emoji
- 禁用绝对化用词（"最好""第一""全网唯一"等）

### 标题公式（小红书特供）

| 公式 | 示例 |
|------|------|
| emoji + 数字 + 结果 | "🔥 3步搞定小红书爆款封面" |
| 身份 + 推荐 + 数字 | "设计师私藏的5个免费素材网站" |
| 反差 + 结果 | "零基础7天学会视频剪辑" |
| 痛点 + 解决 | "总是写不出好标题？这个公式直接套用" |
| 种草 + 限定 | "这个{品类}闭眼入！用了3年还在回购" |

### 标题禁区

```
❌ 绝对化: 最好、第一、全网唯一、100%
❌ 诱导互动: 必须点赞、不转不是中国人
❌ 虚假宣传: 月入百万（无法验证的收益承诺）
❌ 敏感词汇: 见 references/content-rules.md
```

## 标签策略

### 标签配比（5-8 个标签最佳）

```
2 个核心标签: 与内容主题直接相关（搜索流量）
3 个长尾标签: 细分领域/场景标签（精准匹配）
1 个热门标签: 当前平台热点话题（蹭流量）
1-2 个通用标签: #干货分享 #每日分享 等（泛流量）
```

### 标签发现方法

1. 搜索框联想词
2. 笔记详情页底部推荐标签
3. 热门话题广场
4. 竞品笔记标签分析

### 标签格式

```
正确: #小红书运营 #自媒体干货 #涨粉技巧
错误: #小红书运营技巧涨粉方法（太长，无法精准匹配）
```

## 审核规避

详见 → `references/content-rules.md`

### 关键规则

1. **禁用词**：医疗断言、绝对化用语、政治敏感词、竞品诋毁词
2. **站外引流**：不能直接出现微信号、QQ 号、手机号
   - 替代方案：引导"看主页""私信回复关键词"
3. **敏感领域**：医疗、金融、法律内容需格外谨慎
4. **图片审核**：不能有其他平台水印、不能有二维码
5. **视频审核**：不能有其他平台 logo、不能有明显广告

### 限流信号

```
触发限流的行为:
  - 笔记含站外链接/联系方式
  - 大量使用禁用词
  - 短时间内多次编辑已发布笔记
  - 发布后立即删除重发
  - 被多人举报
  - 搬运他人内容
```

## 算法适配

详见 → `references/algorithm-guide.md`

### CES 评分模型

```
CES = 点赞(1) + 收藏(1) + 评论(4) + 转发(4) + 关注(8)

权重优先级: 关注 > 转发 ≈ 评论 > 点赞 ≈ 收藏
```

### 流量池机制

```
初始池: 200-500 曝光
  ↓ CES 达标
二级池: 2000-5000 曝光
  ↓ CES 达标
三级池: 1万-5万 曝光
  ↓ CES 达标
热门池: 10万+ 曝光
```

### 算法优化策略

| 指标 | 优化方法 |
|------|----------|
| 点击率 | 封面+标题优化 |
| 完读率 | 内容节奏+视觉排版 |
| 互动率 | CTA+争议话题+提问 |
| 收藏率 | 干货价值+清单格式 |
| 关注率 | 人设一致性+系列内容 |

# TikTok Content Rules & Compliance

## Community Guidelines Overview

TikTok enforces Community Guidelines globally. Violations lead to content removal, account warnings, temporary bans, or permanent bans.

### Strike System

```
1st violation: Content removed + warning
2nd violation: Content removed + temporary posting ban (24-48h)
3rd violation: Content removed + longer ban (up to 7 days)
4th+ violation: Permanent account ban possible
```

## Prohibited Content

### Absolute Bans

| Category | Examples |
|----------|---------|
| Violence/Harm | Gore, self-harm promotion, dangerous challenges |
| Hate Speech | Attacks based on race, religion, gender, sexuality |
| Harassment | Bullying, doxxing, threats, coordinated attacks |
| CSAM | Any content sexually exploiting minors |
| Terrorism | Promotion of terrorist organizations/acts |
| Illegal Activity | Drug sales, weapons trafficking, fraud schemes |

### Restricted Content

| Category | Rule |
|----------|------|
| Medical claims | Cannot claim to cure/treat conditions; add "not medical advice" |
| Financial advice | No guarantees ("you WILL make $X"); use "not financial advice" |
| Alcohol/Tobacco | Cannot promote; age-gated content only |
| Gambling | Restricted in most regions |
| Political ads | Must comply with local election laws; may be labeled |
| Adult content | No nudity/sexual content; suggestive content may be restricted |

## Copyright & IP

### Music Usage

```
Safe:
  - TikTok Commercial Music Library (for business accounts)
  - Original audio you created
  - Licensed music with proof of license
  - Creative Commons / royalty-free music

Risky:
  - Trending sounds (generally safe for personal accounts)
  - Cover performances (gray area — may get claimed)

Unsafe:
  - Full copyrighted songs as background
  - Movie/TV clips with audio
  - Other creators' original audio without permission
```

### DMCA / Copyright Strikes

```
Process:
  1. Rights holder files takedown notice
  2. TikTok removes content
  3. You receive strike notification
  4. Can file counter-notice if you believe it's fair use

3 copyright strikes = account suspension

Prevention:
  - Use TikTok's built-in music library
  - Create original audio
  - Use royalty-free sources (Epidemic Sound, Artlist)
  - Credit sources in caption
```

## FTC / Advertising Compliance

### Branded Content

```
Required when:
  - You receive payment/free products for promotion
  - Any form of sponsorship or partnership
  - Affiliate link promotion

How:
  - Toggle "Branded Content" in upload settings
  - Include "ad", "sponsored", or "paid partnership" in caption
  - Disclosure must be clear and conspicuous
```

### Income/Earnings Claims

```
Banned phrases:
  - "Guaranteed income"
  - "Make $X per day/week/month"
  - "Get rich quick"
  - "Financial freedom in X days"
  - "This stock/crypto WILL go up"

Allowed (with disclaimer):
  - "Here's how I earned $X" (personal experience)
  - "This method has potential" (with "results may vary")
  - "Not financial advice — do your own research"
```

## External Links Policy

### ⛔ Caption & Video: No External URLs

TikTok prohibits external links in captions and video content. Violations trigger shadowban or content removal.

```
BANNED in caption/video:
  - Any URL (https://github.com/xxx, https://example.com, etc.)
  - QR codes pointing to external sites
  - URL shorteners (bit.ly, t.co, etc.)
  - Spelled-out domains ("visit example dot com")

ALLOWED:
  - Bio link (one link in profile bio)
  - TikTok Shop links (for eligible accounts)
  - @mentions of other TikTok users

SAFE REDIRECT PHRASES:
  - "Link in bio"
  - "Check my profile for the link"
  - "Bio has everything you need"
  - "Tap my profile → link"

COMMON MISTAKE:
  ❌ Inserting GitHub/website/product links in caption
  ✅ Put the link in Bio, caption says "Link in bio"
```

### Why This Matters

- TikTok's algorithm detects URLs and suppresses distribution
- Videos with external links get significantly lower FYP reach
- Repeated violations lead to shadowban (0 views on new content)
- QR codes are scanned by TikTok's image recognition and treated as external links

## Shadowban Prevention

### Content Hygiene

```
DO:
  - Post original content
  - Use TikTok's native editing tools
  - Engage genuinely (reply to comments, duet/stitch)
  - Follow Community Guidelines consistently
  - Remove watermarks from other platforms

DON'T:
  - Repost the same video multiple times
  - Use banned hashtags (#follow4follow, etc.)
  - Mass follow/unfollow
  - Use third-party bot services
  - Cross-post with visible Instagram/YouTube watermarks
  - Post external links in videos (QR codes, URLs)
```

### Sensitive Topics Requiring Extra Care

| Topic | Guidance |
|-------|----------|
| Politics | May get limited distribution; keep factual |
| Religion | Respectful discussion OK; no attacks |
| Mental Health | No glorification; include helpline resources |
| Weight/Body | No shaming; body positivity framing |
| Cryptocurrency | Must include "NFA/DYOR"; no guaranteed returns |
| AI/Deepfakes | Must label AI-generated content |

## Regional Restrictions

```

  - US: FTC compliance, COPPA for kids content
  - EU: GDPR data handling, DSA requirements
  - UK: Age verification requirements
  - India: TikTok banned (use alternative strategies)

  - Local advertising laws
  - Age restriction requirements
  - Data privacy regulations
```

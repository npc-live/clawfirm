# TikTok Algorithm Guide

## For You Page (FYP) Algorithm

### How Content Gets Distributed

```
Upload → Content Review → Initial Test Pool → Expansion → Viral/Decay

Step 1: Content Review (0-30min)
  - Automated scan for policy violations
  - Content classification (topic, language, region)
  - Audio fingerprinting (copyright check)

Step 2: Initial Test Pool (30min-2h)
  - Shown to 200-500 users
  - Audience selected by: device language, location, interests
  - Algorithm measures engagement signals

Step 3: Expansion Decision
  - IF engagement metrics exceed threshold → larger pool (5K-50K)
  - IF metrics are below threshold → limited distribution
  - Multiple expansion rounds possible

Step 4: Viral or Decay
  - High-performing content continues to expand (100K → 1M+)
  - Content can resurface days/weeks later if metrics remain strong
  - Evergreen content (search-optimized) has longest lifespan
```

## Ranking Signals

### Primary Signals (highest weight)

| Signal | Weight | Why It Matters |
|--------|--------|----------------|
| Watch Time / Completion | ★★★★★ | #1 signal — videos watched to end get massive boost |
| Re-watches | ★★★★★ | Looping = extremely strong positive signal |
| Shares | ★★★★ | Highest-weight engagement; signals shareworthy content |
| Profile Visits | ★★★★ | Indicates viewer wants more from you |

### Secondary Signals

| Signal | Weight | Why It Matters |
|--------|--------|----------------|
| Comments | ★★★ | Lengthy comments > emoji-only; conversation = engagement |
| Saves/Favorites | ★★★ | "Bookmark" = high-value content for user |
| Follow-from-video | ★★★ | Strong conversion signal |
| Likes | ★★ | Base engagement metric, lowest weight of interactions |
| Duet/Stitch usage | ★★ | Others creating from your content = strong signal |

### Negative Signals

| Signal | Impact |
|--------|--------|
| "Not interested" | Strong negative — content removed from user's FYP |
| Scroll past quickly (<1s) | Negative — indicates irrelevant content |
| Hide creator | Strong negative for that user relationship |
| Report | Triggers review; if valid, content removed + penalty |

## Completion Rate Optimization

### The #1 Metric

```
Target Completion Rates:
  - ≤15s video: aim for 80%+ completion
  - 15-60s video: aim for 50%+ completion
  - 1-3min video: aim for 30%+ completion

The algorithm weights completion relative to video length.
A 15s video with 90% completion < A 60s video with 60% completion
(total watch time matters too)
```

### Retention Curve Tactics

| Timestamp | Strategy |
|-----------|----------|
| 0-1s | **Pattern interrupt**: unexpected visual/sound/movement |
| 1-3s | **Hook**: "Watch till the end", pose a question, show result first |
| 3-10s | **First payoff**: deliver initial value quickly |
| 10-30s | **Escalation**: "But that's not all" / build tension |
| 30s-end | **Reward + loop**: deliver promise, end at a natural loop point |
| Last 1s | **Loop setup**: edit ending to flow into beginning (for re-watches) |

### Loop Strategy

```
The "infinite loop" technique:
  - End your video right before it naturally loops back to the start
  - Viewers re-watch without realizing → doubles watch time
  - Works best for 7-15s content

How:
  1. Start with a mid-action shot
  2. Tell the story
  3. End on the same mid-action shot
  4. Viewer seamlessly loops back
```

### Content Velocity

```
New Account Strategy:
  - Post 2-3 times daily for first 2-4 weeks
  - Test different content types, times, hashtags
  - Identify what resonates (check analytics after 48h)
  - Double down on top-performing formats

Established Account:
  - 1-2 posts daily, consistent quality
  - Maintain signature style/format
  - Introduce series content (Day 1, Day 2...)
  - Use analytics to optimize posting times
```

## Search & Discovery (SEO)

### TikTok Search Optimization

```
TikTok is becoming a search engine (especially Gen Z).

Optimize for search:
  1. Use keywords in caption (first 40 characters)
  2. Say keywords out loud in video (speech-to-text indexing)
  3. Add keywords in text overlay
  4. Use keyword-rich hashtags
  5. Auto-captions enabled = more indexable content

High-search categories:
  - "How to [X]"
  - "[Product] review"
  - "Best [category] 2026"
  - "[Topic] tutorial"
  - "[City] things to do"
```

## Analytics Interpretation

### Key Metrics Dashboard

```
Views:
  - FYP views = algorithm distribution
  - Profile views = direct interest
  - Search views = SEO working

Engagement Rate:
  - (Likes + Comments + Shares + Saves) / Views × 100
  - Good: 5-10%
  - Great: 10-20%
  - Viral: 20%+

Follower Ratio:
  - Followers gained / Video views
  - Good: 1-3%
  - Great: 3-5%
  - Viral: 5%+

Traffic Sources:
  - For You: algorithm distribution (aim for >70%)
  - Following: loyal audience
  - Search: SEO effectiveness
  - Profile: browse behavior
  - Sound: trending audio discovery
```

### When to Post (Analytics-Driven)

```
1. Go to TikTok Analytics → Followers → Active Times
2. Note peak hours for YOUR audience
3. Post 30-60 minutes BEFORE peak time
4. This gives the algorithm time to test and expand
5. By peak time, your video is in wider distribution
```

# YouTube 格式规范

## 视频标题

| 项目 | 规范 |
|------|------|
| 硬限制 | 100 字符 |
| 搜索可见 | ~70 字符（超出被截断为 "..."） |
| Shorts 屏幕可见 | ~40 字符 |
| 中文计算 | 1 中文字 = 1 字符 |
| 禁用字符 | `< >`（尖括号）及其他无效字符 |
| 多语言 | 支持通过 Content Manager 上传翻译标题（CSV） |

### 标题最佳实践

```
结构:
  [主关键词] + [价值/结果] + [限定词]

示例:
  教程型: "Git 入门教程 — 从零到精通只需1小时 | 2026"
  清单型: "5个提高效率的VS Code插件（程序员必装）"
  对比型: "React vs Vue — 2026年该学哪个？"
  英文: "How to Build a REST API in 10 Minutes (Node.js Tutorial)"

规则:
  - 关键词放在前 30 字符
  - 包含具体数字（提高 CTR 约 20-30%）
  - 避免全大写（"FREE MONEY" → spam 感）
  - 避免过度标点（"!!!" "???"）
  - 年份标记提升时效搜索排名（"2026"）
```

## 视频描述

| 项目 | 规范 |
|------|------|
| 硬限制 | 5,000 字符 |
| 折叠前可见 | ~前 2-3 行（~157 字符） |
| 默认描述 | 支持设置预填充默认描述 |
| 格式化 | 支持加粗、斜体、删除线 |
| 链接 | 支持可点击链接（Shorts 描述中链接不可点击） |
| 修正格式 | 须以 "Correction:" 开头，放在章节之后 |

### 描述结构模板

```
最优结构:

行1-2: [核心摘要 — 包含主关键词，折叠前可见区域]
行3: [CTA: "订阅频道开启通知🔔" 或 "Subscribe for more!"]

---

⏱️ 时间戳 / Chapters:
0:00 引言
1:30 第一部分标题
4:20 第二部分标题
7:00 第三部分标题
9:45 总结

---

📌 本期提到的资源:
- 工具A: [链接]
- 文章B: [链接]

🔗 关注更多:
- Twitter/X: [链接]
- Instagram: [链接]
- 个人网站: [链接]

📧 商务合作: email@example.com

---

#主标签 #副标签1 #副标签2
```

### 描述 SEO 要点

```
关键规则:
  1. 前 1-2 句包含主关键词（YouTube + Google 优先读取）
  2. 自然语言，不要堆砌关键词
  3. 时间戳自动生成视频章节（提高用户体验+SEO）
  4. 添加相关链接（YouTube 会分析链接上下文）
  5. hashtag 放描述末尾（前3个显示在标题上方）

描述长度建议:
  最低: 200+ 字符（给算法足够上下文）
  推荐: 500-2000 字符（SEO最优区间）
  最大: 5000 字符（适合教程类/资源密集型视频）
```

## 视频技术规格

### 长视频

| 项目 | 规范 |
|------|------|
| 时长 | 默认≤15分钟，验证后≤12小时 |
| 格式 | MP4（推荐）、MOV、AVI、WMV、FLV、WebM |
| 编码 | H.264 视频 + AAC 音频 |
| 分辨率 | 推荐 1080p（1920×1080），支持 4K（3840×2160） |
| 帧率 | 24-60fps |
| 大小 | ≤256GB |
| 比例 | 16:9（横屏标准）、9:16（竖屏）、1:1（方形） |

### YouTube Shorts

| 项目 | 规范 |
|------|------|
| 时长 | ≤60秒（推荐 15-60秒） |
| 比例 | 9:16（竖屏，必须） |
| 分辨率 | 1080×1920（推荐） |
| 标题 | ≤100字符（屏幕仅显示~40字符） |
| 描述 | 支持，但链接不可点击 |
| 缩略图 | 不支持自定义，从视频帧中选取 |
| 关键指标 | 完播率 > CTR（Shorts 独立算法） |

### 推荐视频时长

```
按内容类型:
  快速技巧/Tips: 3-5 分钟
  标准教程: 8-15 分钟
  深度分析/研报: 15-30 分钟
  Vlog/纪录: 10-20 分钟
  Shorts: 15-60 秒（15秒官方推荐快速分享）
  
关键:
  - 质量 > 时长（2025算法更新：满意度 > 观看时长）
  - 每分钟都要有价值，砍掉填充内容
  - 留存率高的短视频 > 留存率低的长视频
```

## 缩略图规范

### 基本参数

| 项目 | 规范 |
|------|------|
| 推荐分辨率 | 1280×720 |
| 最小宽度 | 640px |
| 比例 | 16:9 |
| 格式 | JPG, PNG, GIF, BMP |
| 大小 | ≤2MB |
| 上传限制 | 每频道每日有上传次数限制 |
| Shorts | 不支持自定义缩略图 |
| API | POST /thumbnails/set（不匹配尺寸会自动缩放+黑边） |

### 缩略图设计指南

```
文案层:
  - 3-6 个字/词（核心信息）
  - 大号粗体字（手机端清晰可辨）
  - 高对比色（深底浅字 或 浅底深字）
  - 与标题互补而非重复

视觉层:
  - 人脸/表情（增加点击欲望）
  - 明亮饱和色彩（从feed中脱颖而出）
  - 简洁构图（一个焦点）
  - 品牌一致性（字体/色彩/风格统一）

安全区域:
  - 右下角: 被视频时长标签遮挡 — 不放关键信息
  - 左下角: 部分界面有进度条 — 避免放文字
  - 中心和右侧: 最安全的文字区域

避免:
  - 低分辨率/模糊图片
  - 文字过多导致信息过载
  - 与视频内容不符的误导性图片（违反社区准则）
  - 带有其他平台水印的图片
```

## 社区帖子（Community Post）

### 基本参数

| 项目 | 规范 |
|------|------|
| 文字限制 | ≤1,400 字符 |
| 投票选项 | 2-5 个选项，每选项≤65字符 |
| 图片 | 支持 |
| GIF | 支持 |
| 视频链接 | 支持（关联已有YouTube视频） |
| 解锁条件 | 500+ 订阅者 |
| 频率限制 | 每日 1-2 条为宜（过多触发限制） |

### 帖子类型与效果

| 类型 | 互动率 | 适用场景 |
|------|--------|----------|
| 投票 | ★★★★★ | 选题调研、观众参与 |
| 图片 | ★★★ | 幕后花絮、预告 |
| 视频链接 | ★★★★ | 推广旧视频、引流 |
| GIF | ★★★★ | 幽默互动、反应 |
| 纯文字 | ★★ | 快速更新、公告 |

### 社区帖子排版

```
互动型:
  [提问/讨论话题]
  [1-2行上下文]
  [投票/引导评论]

预告型:
  [新视频预告/进展更新]
  [图片/截图]
  [发布时间预告]

推广型:
  [推荐理由 — 1-2句]
  [视频链接]
  [CTA: "你看过了吗？"]
```

## Hashtag 规范

### 使用规则

| 项目 | 规范 |
|------|------|
| 最大数量 | ≤15 个（超过可能导致全部失效） |
| 标题上方显示 | 前 3 个 hashtag |
| 推荐数量 | 3-5 个 |
| 放置位置 | 描述末尾（推荐）或标题中 |
| Shorts 必备 | #Shorts |

### Hashtag 选择

```
组合建议:
  1个核心主题标签 + 1-2个细分标签 + 1个趋势/年份标签

示例:
  技术类: #编程教程 #Python #2026
  加密类: #Bitcoin #CryptoAnalysis #Web3
  生活类: #Vlog #日常 #生活记录
  英文: #Tutorial #HowTo #TechTips

避免:
  - 无关热门标签（降权）
  - 误导性标签
  - 过度使用（>15个全部失效）
  - 仅由标签组成的描述（无实质内容）
```

## 字幕 / CC

```
支持格式: SRT, SBV, VTT, TTML 等
自动生成: YouTube 自动语音识别（准确度有限）
手动上传: 推荐，提高准确性和 SEO
多语言: 支持上传多语言字幕

SEO 价值:
  - YouTube 索引字幕内容用于搜索排名
  - 多语言字幕扩大国际受众
  - 提高无障碍性（Accessibility）
```

## 禁用字符

```
标题和描述中:
  ❌ < >（尖括号）— 不允许使用
  
替代方案:
  ❌ <重要>          → ✅ 【重要】或 (重要)
  ❌ price < $100    → ✅ price under $100
  ❌ ROI > 500%      → ✅ ROI over 500%
  ❌ <link>          → ✅ [link] 或直接放URL
```

## End Screen（片尾画面）与 Cards（卡片）

```
End Screen:
  - 视频最后 5-20 秒可添加
  - 元素: 订阅按钮、推荐视频、播放列表、频道、外部链接
  - 设计: 预留干净的背景区域给 End Screen 元素

Cards:
  - 视频播放中任意时间点可插入
  - 类型: 视频/播放列表链接、频道链接、投票、外部链接
  - 文案: 简短有力的提示文字（"查看完整教程→"）
  
文案配合:
  - 视频口播中提及 "点击右上角卡片查看..."
  - End Screen 前口播引导 "接下来看这个视频..."
```

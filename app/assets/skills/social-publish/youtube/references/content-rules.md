# YouTube 平台规则

## 社区准则核心政策

### 禁止内容类别

#### 1. 误导性元数据（Misleading Metadata）

```
严格禁止:
  - 标题与视频内容严重不符（clickbait）
  - 缩略图使用误导性图片/文字
  - 描述中放置虚假信息
  - 标签/hashtag 与内容无关（蹭流量）
  - 伪装成新闻/官方公告的虚假内容

后果:
  - 内容降权/从推荐中移除
  - 内容删除 + 邮件通知
  - 累计违规: 警告 → 罢工(Strike) → 频道终止
```

#### 2. 垃圾内容与欺骗行为（Spam & Deceptive Practices）

```
严格禁止:
  - 过度/无关标签（Tag Spam）
  - 重复上传相同或极相似的视频
  - 人为操纵互动指标（买赞/买评论/买订阅）
  - 自动化垃圾评论
  - 虚假参与度（互粉互赞群组）
  - 引导用户离开 YouTube 的欺骗性行为

后果:
  - 内容删除
  - 频道警告/罢工
  - 严重者频道终止
```

#### 3. 外部链接规则

```
允许:
  - 指向安全、合规内容的外部链接
  - 社交媒体链接
  - 个人网站/博客链接
  - 联盟/推广链接（需遵守披露规则）

禁止:
  - 链接到违反社区准则的内容
  - 恶意链接（钓鱼、恶意软件）
  - YouTube 无法验证为安全的链接（可能被移除）

特殊:
  - Shorts 描述和评论中的 URL 不可点击
  - 联盟内容本身不违反 ToS，但过度推广可能触发 spam 政策

后果:
  - 违规链接被移除
  - 内容删除 + 警告
  - 累计违规可导致罢工和频道终止
```

#### 4. 版权政策

```
核心规则:
  - 只上传自己制作或获得授权的内容
  - 不得未经许可使用他人的音乐、视频片段、图片
  - Fair Use 有严格条件（评论/教育/新闻等），不能想当然

Content ID 系统:
  - 自动扫描上传视频与版权数据库匹配
  - 匹配时: 版权方可选择静音/屏蔽/收入归版权方
  - 创作者可提出争议

版权罢工（Copyright Strike）:
  - 版权方提交正式移除请求
  - 3次罢工 = 频道终止
  - 罢工有效期 90 天
  - 可通过反通知或版权方撤回解决

安全做法:
  - 使用 YouTube 音频库（免费音乐/音效）
  - 使用有授权的素材库
  - 引用标注来源（但标注来源≠免于侵权）
  - 获取书面授权
```

#### 5. 侵权与不当内容

```
禁止:
  - 仇恨言论、歧视
  - 骚扰与网络欺凌
  - 暴力/血腥内容（教唆、美化）
  - 危险行为（挑战、恶作剧）
  - 误导性医疗/健康信息
  - 儿童安全相关违规（COPPA）
  - 色情/成人内容（未标记）
  - 恐怖主义/极端主义内容

后果:
  - 内容删除
  - 频道限制/年龄限制
  - 罢工/频道终止
  - 严重者上报执法机构
```

## 罢工与处罚体系

### 社区准则罢工（Community Guidelines Strike）

```
第一次违规 → 警告（Warning）:
  - 创作者收到邮件通知
  - 可完成政策培训
  - 培训完成后 90 天内无再犯则警告过期

第一次罢工:
  - 1 周内无法上传视频/直播/发帖
  - 罢工 90 天后过期

第二次罢工（90天内）:
  - 2 周内无法发布任何内容

第三次罢工（90天内）:
  - 频道永久终止

注意:
  - 严重违规可跳过警告直接终止
  - 罢工期间功能受限
  - 可提出申诉
```

### 版权罢工

```
累计:
  - 1次罢工: 需完成版权学校
  - 3次有效罢工: 频道终止 + 所有视频删除
  - 罢工 90 天后过期（如无新罢工）

解决方式:
  - 等待 90 天过期
  - 联系版权方撤回
  - 提交反通知（Counter Notification）
```

## 内容降权因素

### 确认降权

```
明确降权:
  - 被多人举报的内容
  - 违反社区准则被标记的内容
  - 标题/缩略图误导（标题与内容不符）
  - 过度/无关标签
  - 重复内容（与自己或他人重复）
```

### 可能降权

```
可能降权:
  - 高跳出率（观众看了开头就走 — 标题过度承诺）
  - "不感兴趣" 反馈过多
  - 低互动率（曝光后无人互动）
  - 过多外部链接
  - 频繁删除后重新上传（试图重置数据）
  - 与频道定位不符的内容（混乱的内容方向）
```

### 降权处理建议

```
如果怀疑被降权:
  1. 检查 YouTube Studio 分析:
     - 曝光量（Impressions）是否突然下降
     - CTR 是否异常
     - 留存率是否低于频道平均
  2. 检查近期内容是否触发规则
  3. 提高缩略图/标题质量（提升 CTR）
  4. 提高内容质量（提升留存率）
  5. 确保标题兑现内容承诺
  6. 删除无关/过度标签
```

## Spam 防控机制

### 触发 Spam 标记

```
触发条件:
  - 重复上传相同/极相似视频
  - 短时间大量发布（尤其是社区帖子）
  - 描述/评论中大量外部链接
  - 使用与内容无关的热门标签
  - 自动化发布行为特征
  - 评论区大量重复评论
  - 诱导点击/订阅的欺骗行为
```

### 安全做法

```
安全阈值:
  - 长视频: 每日 ≤3 条
  - Shorts: 每日 ≤5 条
  - 社区帖子: 每日 ≤2 条
  - 每个视频内容独特
  - 标签相关且不过度（5-15个 tags，3-5个 hashtags）
  - 描述有实质内容（不仅仅是链接和标签）

推荐:
  - 混合内容类型（长视频 + Shorts + 社区帖子）
  - 真实互动（回复评论、参与讨论）
  - 内容有信息增量
  - 自然的发布节奏
```

## 变现合规（Monetization）

### YouTube 合作伙伴计划（YPP）门槛

```
申请条件:
  - 1,000+ 订阅者
  - 过去 12 个月 4,000+ 公开观看小时
    或 过去 90 天 1000万+ Shorts 观看次数
  - 遵守所有 YouTube 政策
  - 关联 Google AdSense 账号
  - 所在地区开放 YPP
```

### 影响变现的内容

```
可能被黄标（Limited Ads）:
  - 争议性话题
  - 敏感事件
  - 粗俗语言
  - 暴力内容（即使非违规）
  - 药物/酒精相关

完全无法变现:
  - 违反社区准则的内容
  - 被版权声明的内容（收入归版权方）
  - 重复使用他人内容
  - 自动生成的低价值内容
```

## 发帖前检查清单

```
发布前自检:
  □ 标题准确反映视频内容（不误导）
  □ 标题 ≤70 字符（搜索可见区域内）
  □ 描述前2行包含核心信息和关键词
  □ 标签与视频内容相关（无 spam 标签）
  □ Hashtag ≤15 个，推荐 3-5 个
  □ 缩略图清晰、不误导、符合社区准则
  □ 不含违规外部链接
  □ 不含版权侵权内容
  □ 不含尖括号 < >（平台禁用字符）
  □ 内容原创（非重复/搬运）
  □ Shorts 描述中无链接（不可点击）
  □ 推广/联盟内容已适当披露
```

# YouTube 推荐算法

## 推荐系统概览

### YouTube 不是一个算法，而是多个推荐系统

```
YouTube 有多个独立的推荐系统，分别服务不同的内容发现场景:
  - 首页（Home）推荐
  - 搜索（Search）排名
  - 推荐视频（Suggested Videos）
  - Shorts Feed
  - 订阅（Subscriptions）
  - 热门/趋势（Trending）

核心事实:
  - 算法驱动 ~70% 的观看量
  - 每分钟上传 500+ 小时视频，算法的任务是匹配
  - 算法为观众服务，不为创作者服务
  - 2025更新: 满意度 > 单纯观看时长
```

---

## 各推荐场景详解

### 1. 首页（Home Feed）

```
触发: 用户打开 YouTube 首页
个性化: 基于用户的观看历史、搜索历史、时间、设备

排名信号:
  - 视频表现: CTR + 观看时长 + 互动
  - 用户匹配: 与用户兴趣/历史的相关性
  - 新鲜度: 新内容有一定加权
  - 频道关系: 用户与频道的互动历史

特点:
  - 最大的流量入口之一
  - 高度个性化（同一视频对不同用户排名不同）
  - 考虑时间/场景（午休 vs 晚间，手机 vs 电视）
```

### 2. 搜索（Search）

```
触发: 用户主动搜索关键词
排名信号:
  - 相关性: 标题/描述/标签与搜索词的匹配度
  - 表现: 来自搜索的 CTR + 观看时长
  - 频道权威: 在该主题领域的历史表现
  - 用户个性化: 基于用户历史微调排名

SEO 关键:
  - 标题含目标关键词（前 30 字符）
  - 描述前 2 行含关键词（自然语言）
  - 标签包含精确和长尾关键词
  - 字幕/CC 被索引用于搜索排名
  - 视频内容本身被 AI 分析（2025: Gemini 分析语义/画面）
```

### 3. 推荐视频（Suggested Videos）

```
触发: 用户正在观看某个视频时，右侧/下方推荐
排名信号:
  - 主题相关: 与当前视频的主题匹配
  - 用户历史: 用户的长期兴趣图谱
  - 共同观看: "看了A也看了B"的协同过滤
  - 会话延续: 能让用户继续看下去的内容

优化策略:
  - 做系列内容（系列视频互相推荐）
  - 与同领域创作者内容主题呼应
  - End Screen 引导看下一个视频
```

### 4. Shorts Feed

```
独立算法: Shorts 有自己的推荐系统
核心指标: 完播率 > CTR（与长视频不同）

排名信号:
  - 完播率（Completion Rate）— 最核心
  - 重播率（Replay Rate）— 强正面信号
  - 点赞/评论/分享
  - 订阅转化（看了Shorts后订阅）
  - "不感兴趣" 负面反馈

特点:
  - 90亿+ 日均观看量
  - 独立的内容池和推荐系统
  - 对新频道/小频道更友好（内容导向 > 频道大小）
  - Shorts 可为长视频频道引流
```

## 核心推荐因子

### 正面因子（按权重排序）

```
1. CTR（点击率）               ★★★★★
   - 缩略图 + 标题决定
   - 平均 4-6%，7%+ 为优秀
   - 第一关卡: CTR 不够就没有后续

2. 留存率（Audience Retention） ★★★★★
   - 观众平均看了视频的百分之几
   - 50-60% 为合格，70%+ 为优秀
   - 前 30 秒留存最关键

3. 观看时长（Watch Time）       ★★★★
   - 总观看分钟数
   - 2025更新: 不再盲目追求长视频
   - 短但高留存 > 长但低留存

4. 满意度（Satisfaction）       ★★★★
   - 点赞/分享比例
   - 用户满意度调查（YouTube 会随机调查）
   - "不感兴趣"/"不推荐此频道" 为强负面信号

5. 互动（Engagement）           ★★★
   - 评论数量和质量
   - 分享到外部平台
   - 收藏到播放列表

6. 会话贡献（Session Watch Time）★★★
   - 看完你的视频后用户是否继续看其他视频
   - 让用户"留在 YouTube" = 正面信号
   - End Screen + 推荐下一视频 有帮助

7. 频道权威度                   ★★
   - 在特定主题领域的持续输出
   - 历史表现和观众口碑
   - 新频道/小频道通过单个视频突破也可能
```

### 负面因子

```
强负面:
  - "不感兴趣" 点击
  - "不推荐此频道" 点击
  - 举报
  - 高跳出率（点开秒退）

中等负面:
  - 低互动率（曝光但无人点击）
  - Dislike 比例过高
  - 评论区大量负面反馈

轻度负面:
  - 长期不更新
  - 内容方向频繁变化
```

## 四级分发模型

```
阶段1: 初始分发（上传后 0-2 小时）
  - 推送给: 订阅者 + 少量匹配用户
  - 评估: CTR + 早期留存率
  - 样本: 数百到数千次曝光
  - 关键: 前 48 小时决定视频命运

阶段2: 扩大分发（2-48 小时）
  - 条件: 阶段1指标达标（CTR + 留存优于平均）
  - 推送给: 更大范围的兴趣匹配用户
  - 进入: 首页推荐 / 推荐视频 / 搜索排名提升
  - 样本: 数千到数万次曝光

阶段3: 大规模分发（48小时-2周）
  - 条件: 持续优秀的 CTR + 留存 + 满意度
  - 推送给: 全站范围推荐
  - 可能进入: 热门/趋势
  - 效果: 数万到数百万次曝光

阶段4: 长尾/常青（2周+）
  - 条件: 搜索排名稳定 + 持续获得推荐视频流量
  - 特点: 教程/知识类内容有长尾效应
  - 可能持续获得流量数月甚至数年
```

## 黄金窗口期

```
关键: 上传后 48 小时决定视频的推荐上限

优化策略:
  1. 在目标受众最活跃时段发布
  2. 发布前确保缩略图/标题已优化
  3. 发布后立即回复早期评论
  4. 在社区帖子/社交媒体预告新视频
  5. 利用 Shorts 为新长视频引流
  6. 不要在发布后频繁修改标题/缩略图（可能重置数据）
  
  例外: 搜索导向内容（教程/How-to）可以慢热，
  不完全依赖前 48 小时
```

## 内容类型偏好

### 算法偏好的内容

```
高推荐概率:
  + 系列内容（固定格式/主题，2025 重点更新）
  + 高留存率的视频（不论长短）
  + 引发大量评论/分享的内容
  + 与频道定位一致的内容
  + 搜索需求量大的主题（搜索流量常青）
  + 有字幕/CC 的视频（更广覆盖+SEO）

低推荐概率:
  - 低留存率内容（观众快速退出）
  - 标题党（高CTR+低留存 = 严重降权）
  - 重复/搬运内容
  - 与频道定位不符的内容
  - 无互动的内容
  - 自动生成的低质量内容
```

### 各类型内容策略

```
教程/知识类:
  - 标题含搜索关键词
  - 描述+标签覆盖长尾关键词
  - 时间戳/章节提高用户体验
  - 长尾流量潜力大
  - 留存率是关键（不废话直入主题）

娱乐/Vlog 类:
  - 缩略图+标题的 CTR 是关键
  - 前 30 秒 Hook 决定留存
  - 依赖首页/推荐视频流量
  - 更新频率影响推荐稳定性

Shorts:
  - 完播率 > 一切
  - 前 1-2 秒抓注意力
  - 简短有力（15-30秒最佳完播率）
  - 循环感/重播感增加重播率
  - #Shorts 标签必备
```

## 互动优化策略

### 提升 CTR（点击率）

```
缩略图:
  - 大字体 + 人脸表情 + 高对比色
  - 与标题互补（不重复）
  - A/B 测试不同风格（YouTube Studio 支持）
  - 保持品牌一致性

标题:
  - 前 30 字符放关键信息
  - 包含数字（"7个方法" vs "几个方法"）
  - 制造信息缺口（好奇但不欺骗）
  - 避免全大写和过度标点
```

### 提升留存率

```
技巧:
  - 前 30 秒 Hook（痛点/成果/悬念/反常识）
  - 预告内容结构（"今天讲3个要点"）
  - 视觉变化（镜头切换/B-Roll/图表/文字叠加）
  - 节奏控制（不拖沓，每分钟都有价值）
  - 用"但是...""然而...""还没完..."制造悬念
  - 砍掉废话（2025算法: 满意度 > 时长）
```

### 引导互动（评论/分享）

```
技巧:
  - 视频中提问: "你觉得{话题}怎么样？评论告诉我"
  - 争议性观点引发讨论
  - 请求: "觉得有用就点个赞/分享给需要的朋友"
  - 置顶评论中追加问题或补充信息
  - 积极回复评论（尤其前 2 小时的早期评论）
  - 投票/选择题: "A还是B？评论区告诉我"
```

## Shorts 算法专题

```
独立推荐系统:
  Shorts 不与长视频共享推荐池

核心指标排序:
  1. 完播率（看完/总观看） — 最核心
  2. 重播率 — 强正面信号
  3. 点赞率
  4. 评论率
  5. 分享率
  6. 订阅转化率

最佳实践:
  - 15-30秒完播率最高
  - 前1秒必须抓住注意力（无开场白直入主题）
  - 循环设计（结尾接开头，鼓励重播）
  - 竖屏 9:16 必须
  - 含 #Shorts 标签
  - 描述中不放链接（不可点击）
  - 每日 1-3 条保持曝光

对长视频频道的价值:
  - Shorts 可为频道带来新订阅者
  - 新订阅者可能被推荐频道的长视频
  - Shorts 是小频道最快的增长路径
```

## 搜索 SEO 优化

```
关键词研究:
  - YouTube 搜索建议（输入关键词看自动补全）
  - Google Trends（YouTube 搜索过滤器）
  - 竞品分析（热门视频用了什么关键词）

标题优化:
  - 主关键词在前 30 字符
  - 具体化 > 宽泛（"Python 爬虫教程" > "编程教程"）
  - 年份标记提升时效搜索（"2026"）

描述优化:
  - 前 2 行含主关键词（自然语言）
  - 500-2000 字符最优
  - 时间戳/章节提高 SEO + 用户体验

标签优化:
  - 精确关键词 + 长尾变体 + 宽泛类目
  - 不堆砌、不误导
  - 总计 ~500 字符以内

字幕/CC:
  - YouTube 索引字幕用于搜索
  - 手动上传 > 自动生成（准确性）
  - 多语言字幕扩大国际覆盖

多语言:
  - 通过 Content Manager 上传翻译标题/描述（CSV）
  - 为非英语内容添加英文翻译标题
  - 扩大搜索覆盖面
```

## 频道增长策略

```
内容策略:
  - 明确频道定位（算法需要理解你的频道）
  - 系列化内容（2025 更新: 系列格式优先推荐）
  - 混合搜索型+推荐型内容
  - Shorts 引流 + 长视频深度 组合

发布策略:
  - 固定发布节奏（每周X天固定时间）
  - 在受众活跃时段发布
  - 发布前在社区帖子预告
  - 发布后 2 小时内积极互动

频道优化:
  - 频道简介含关键词
  - 频道 Banner 传达定位
  - 播放列表组织内容（增加会话时长）
  - 频道 Trailer 吸引新访客

跨平台引流:
  - Shorts → 长视频
  - 社区帖子 → 新视频
  - Twitter/Instagram → YouTube
  - 博客/Newsletter → 视频内容
```

# YouTube 内容创作

## 文案风格

### 核心调性：价值驱动 + SEO 友好 + 观众导向

- **价值承诺**：标题和描述必须明确告诉观众"看完能得到什么"
- **搜索友好**：关键词自然融入标题和描述前两行
- **真实可信**：不夸大、不误导，内容兑现标题承诺
- **对话感**：像和观众 1:1 聊天，而非播音腔
- **中英双语**：根据目标受众选择，YouTube 国际化程度极高

### 语气参考

```
教程型: "如何{目标}（完整教程）" / "How to {Goal} — Step by Step Guide"
清单型: "{数字}个{方法}让你{结果}" / "{N} {Methods} That Actually Work in 2026"
对比型: "{A} vs {B} — 哪个更适合你？" / "{A} vs {B}: Which One Should You Pick?"
故事型: "我花了{时间}{做了什么}，结果..." / "I Tried {X} for {Time} — Here's What Happened"
解析型: "{现象}背后的真相" / "The Truth Behind {Topic} Nobody Talks About"
速报型: "{事件}最新进展 — 你需要知道的一切"
```

### 避免的写法

```
避免:
  - 标题党: "震惊！""你绝对想不到！"（触发 clickbait 审核）
  - 误导性: 标题与视频内容不符（降低推荐权重+观众信任）
  - 全大写: "HOW TO MAKE MONEY FAST!!!"（垃圾感）
  - 关键词堆砌: 标题/描述中反复塞关键词（spam 嫌疑）
  - 空洞承诺: "改变你一生的视频"（无具体信息）

推荐:
  - 具体化（数字 + 结果 + 时间框架）
  - 前置关键词（搜索优化）
  - 标题兑现内容（高留存 = 高推荐）
  - 激发好奇但不欺骗
```

## 格式规范

详见 → `references/format-specs.md`

### 内容类型一览

| 类型 | 字数/时长限制 | 适用场景 |
|------|-------------|----------|
| 长视频标题 | ≤100字符（建议≤70字符） | 教程、分析、Vlog |
| 长视频描述 | ≤5,000字符 | SEO、链接、章节 |
| Shorts 标题 | ≤100字符（屏幕仅显示~40字符） | 短内容、快节奏 |
| 社区帖子 | ≤1,400字符 | 互动、预告、投票 |
| 评论 | ≤10,000字符 | 置顶评论、互动 |
| 播放列表标题 | ≤100字符 | 内容组织 |
| 频道简介 | ≤1,000字符 | 频道定位 |

### 标题写作规范

```
硬限制: 100 字符
搜索可见: 约 70 字符（超出部分被截断为"..."）
Shorts 屏幕可见: 约 40 字符

标题公式:
  [主关键词] — [价值承诺/具体结果] | [补充标签]
  示例: "Python 爬虫入门 — 30分钟学会自动采集数据 | 2026教程"
  示例: "5 Email Subject Lines With 40%+ Open Rates"

规则:
  - 主关键词放在前 30 字符内
  - 包含具体数字（提高 CTR）
  - 不使用无效字符（< > 等）
  - 中文标题用阿拉伯数字，不用汉字数字
  - 英文标题首字母大写（Title Case）
```

### 描述写作规范

```
硬限制: 5,000 字符
折叠前可见: 约前 2-3 行（~157 字符）— 最关键的区域

描述结构:
  第 1-2 行: [核心摘要 + 主关键词]（折叠前可见）
  第 3-5 行: [CTA — 订阅/点赞/链接]
  后续: [时间戳/章节] [详细说明] [相关链接] [社交媒体]
  末尾: [标签 #Tag1 #Tag2 #Tag3]

格式化:
  - 支持加粗、斜体、删除线（描述编辑器）
  - 修正内容须以 "Correction:" 或 "Corrections:" 开头
  - 修正内容放在章节时间戳之后
```

**视频描述排版：**

- [链接2]

## 标签策略

### Tags（视频标签）

```
总字符限制: ~500 字符（平台观测值，官方仅警告不得过度使用）
建议数量: 5-15 个
放置位置: YouTube Studio 上传/编辑页面的"标签"字段

标签选择:
  必选（1-2个核心关键词标签）:
    与视频主题完全匹配的精确词

  推荐（3-5个相关标签）:
    同义词、近义词、长尾关键词

  可选（3-5个宽泛标签）:
    领域/类目标签

避免:
  - 与内容无关的标签（违反 spam 政策，可能被删除）
  - 关键词堆砌（过度使用标签降权）
  - 误导性标签（如蹭热点名人/事件但内容无关）
```

### Hashtags（描述/标题中的 # 标签）

```
数量限制: ≤15 个（超过可能导致全部失效，观测值）
显示规则: 前 3 个 hashtag 会显示在视频标题上方
放置位置: 描述末尾（推荐）或标题中

组合建议:
  1个品牌标签 + 1-2个主题标签 + 1-2个趋势标签

示例:
  #Python教程 #编程入门 #2026
  #CryptoAnalysis #Bitcoin #Web3

Shorts 特殊:
  务必包含 #Shorts 标签
  Shorts 描述中的 URL 不可点击 — 不要放链接
```

## 缩略图文案策略

### 技术规格

| 项目 | 规范 |
|------|------|
| 推荐分辨率 | 1280×720（最小宽度 640px） |
| 比例 | 16:9 |
| 格式 | JPG, PNG, GIF, BMP |
| 大小 | ≤2MB |
| Shorts | 不支持自定义缩略图，使用视频帧 |

### 缩略图文案原则

```
文字量: 3-6 个字/词（手机端要能清晰阅读）
字体: 大号、高对比度、粗体
位置: 居中或偏右（左侧被时长标签遮挡）

公式:
  [关键词/数字] + [情绪表情/反应] + [高对比背景]
  
示例:
  "月入10万" + 震惊表情 + 渐变背景
  "5 MISTAKES" + 红色X标记 + 深色背景

避免:
  - 文字过小（手机端看不清）
  - 文字过多（>8个词信息过载）
  - 与标题完全重复（浪费传达空间）
  - 误导性图片/文字（违反社区准则，可能被警告）
  - 低分辨率/模糊图片
```

|-------------------|------|----------|

### 发布频率

```
推荐:
  - 长视频: 每周 1-3 条（质量 > 数量）
  - Shorts: 每日 1-3 条（高频利于 Shorts 推荐）
  - 社区帖子: 每日 1-2 条（保持频道活跃）

关键:
  - 保持稳定的发布节奏（算法偏好一致性）
  - 系列内容优先（2025更新：系列格式获得优先推荐）
  - 不要一次性大量发布（互相抢流量）
```

## 风控规则

详见 → `references/content-rules.md`

### 关键合规要点

| 风险行为 | 后果 |
|----------|------|
| 标题/缩略图误导（clickbait） | 降权 / 内容删除 |
| 过度/无关标签 | Spam 标记 / 内容删除 |
| 描述中放违规链接 | 内容删除 / 警告 / 罢工 |
| 缩略图违反社区准则 | 警告 / 罢工 / 封号 |
| 抄袭/搬运他人内容 | 版权罢工 / 频道终止 |
| 误导性元数据 | 降权 / 内容删除 |
| 重复上传相同内容 | Spam 标记 |

### 合规文案必备

```
通用:
  - 标题必须准确反映视频内容
  - 描述前两行不放误导信息
  - 标签与视频内容相关

带链接的描述:
  - 不放违反社区准则的链接
  - 联盟/推广链接需遵守披露规则
  - YouTube 可能移除无法验证为安全的链接

版权注意:
  - 使用的音乐/素材需有授权
  - 引用他人内容标注来源
  - Fair Use 有严格条件，不要想当然
```

## 算法适配

详见 → `references/algorithm-guide.md`

### 核心推荐因子

```
权重排序:
  1. CTR（点击率）      — 缩略图+标题决定，4-6%平均，7%+优秀
  2. 留存率             — 观众看了视频多少比例，50-60%合格，70%+优秀
  3. 观看时长           — 总观看分钟数
  4. 观众满意度         — 点赞/分享/调查反馈/"不感兴趣"
  5. 评论/互动          — 引发讨论 = 好内容
  6. 会话贡献           — 看完你的视频后继续看其他视频（平台留存）
  7. 频道权威度         — 在特定领域的持续输出和观众认可
```

### 算法友好策略

| 策略 | 说明 |
|------|------|
| 优化缩略图+标题 | CTR 是第一关，过不了就没有后续 |
| 前 30 秒抓注意力 | 开头决定留存曲线 |
| 内容兑现承诺 | 标题承诺什么就给什么（高满意度） |
| 引导评论 | 末尾提问/争议话题/互动引导 |
| 系列内容 | 固定系列让算法更精准匹配受众 |
| 稳定更新频率 | 算法偏好持续活跃的频道 |
| 用 Shorts 引流 | Shorts 有独立推荐池，可为长视频导流 |
